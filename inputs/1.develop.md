Your task is to write a complete, production-ready Python REST API that performs CRUD operations for a user management system using a SQLite database.

# Tech Stack:
- Language: Python 3.10+
- Framework: FastAPI
- Database: SQLite (using SQLAlchemy ORM)

# Data Model:
The User table must record the following fields:
- id (Primary Key)
- name (String, required)
- surname (String, required)
- age (Integer, required, must be > 0)

# Required Endpoints:
- POST /users/ - Create a new user.
- GET /users/ - Retrieve a list of all users.
- GET /users/{user_id} - Retrieve a specific user by ID.
- PUT /users/{user_id} - Update a specific user's details.
- DELETE /users/{user_id} - Delete a specific user.
